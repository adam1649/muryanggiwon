# 무량기원 (無量棋院 · MURYANG BADUK INSTITUTE)

바둑의 깊이는 헤아릴 수 없다 · 無量之棋 · 無盡之道

무량사(MURYANGSA)의 3D 엔진(아바타 · 실시간 방문객 · 카메라 · 낮밤 · 품질 레이어)을 그대로 이어받아 만든 **가상의 현대식 바둑 전문 기관**입니다. 한국기원처럼 현대 한국에 있을 법한 석재·유리·금속 건물이고, 안에서 **실제로 바둑을 둘 수 있습니다**(인공지능 · 다른 방문객과 함께 · 관전).

무량사와는 **방(서버)과 공간을 분리**했습니다. 같은 주소(도메인) 아래에 두면 방문객 이름 · 옷 꾸미기 · 화질/마우스 설정은 무량사와 이어서 쓰입니다.

## 파일 구성
- `index.html` : 메인 페이지
- `src/main.js` : 3D 기원(건물 · 실내 · 아바타 · 실시간 연결 · 바둑 대국 동기화)
- `src/go_engine.js` : 바둑 규칙 엔진 + 인공지능 + 계가
- `src/go_worker.js` : 인공지능·계가를 화면과 따로 계산하는 작업자(Web Worker)
- `src/baduk_ui.js` : 바둑판 창(대국 준비 · 착수 · 관전 · 계가 표시)
- `src/quality.js` : 무량사와 같은 품질 레이어(절차 질감 · 하늘 · 반사 · 블룸)
- `style.css` : 무량사 디자인 + 무량기원 바둑판 창
- `assets/` : 사이트 아이콘(금빛 棋)
- `sample_image1.png` : 대표 이미지(화면에는 표시하지 않음)

## 바둑 두기
1. 빈 대국석 가까이 가서 **E(바둑 두기)** — 의자(방석)에 앉으면 바둑판 창이 열립니다. 「바로 대국하기」를 누르면 대국장의 빈 자리로 바로 갑니다.
2. 상대를 고릅니다.
   - **인공지능**: 입문 · 초급(수읽기 휴리스틱) / 중급 · 고급(몬테카를로 트리 탐색). 판 크기 9 · 13 · 19줄, 내 돌 흑 · 백 · 무작위. 무르기 가능.
   - **방문객 기다리기**: 맞은편 의자에 다른 방문객이 앉으면 바로 대국이 시작됩니다. 「한 판 청하기」(방문객을 눌러 나오는 메뉴)로 신호를 보낼 수 있습니다.
3. 판을 눌러 착수합니다. 모바일은 **한 번 눌러 미리 보고, 같은 자리를 한 번 더 눌러 착수**합니다.
4. 두 번 연속 패스하면 **자동 계가**합니다. 사석은 무작위 대국을 여러 번 돌려 소유를 추정해 판정하고(× 표시), 집은 작은 네모로 보여 줍니다.
- 규칙: 한국 규칙(집 + 따낸 돌 + 사석), **덤 6.5집**, 자충수 금지, 단순 패 금지.
- **관전**: 대국 중인 자리 가까이에서 **F**, 또는 3D 바둑판을 누르면 실시간으로 봅니다. 대국장 뒷벽 전광판과 로비 화면은 가장 최근에 움직인 대국을 중계합니다.
- 앉아 있을 때 **B**로 바둑판 창을 다시 열고, **Esc**로 닫습니다. 움직이거나 「일어나기」를 누르면 자리에서 일어납니다(인공지능 대국은 정리되고, 방문객 대국은 상대의 승리로 끝납니다).
- 내 돌을 놓으면 캐릭터가 손을 뻗어 판에 돌을 놓는 동작을 하고, "딱" 소리가 납니다. 대국장 안에서는 어딘가에서 돌 놓는 소리가 은은하게 들립니다.

## 실시간 방문객 (서버 없음)
- 무량사와 같은 Trystero(WebRTC) 방식이며, 방 이름은 `muryanggiwon-open`(앱 ID `org.muryanggiwon.v1`)으로 **무량사와 분리**되어 있습니다. 주소 뒤 `?room=친구방이름`으로 비공개 방을 열 수 있습니다.
- 대국 동기화: 대국을 연 사람(호스트)이 판정의 기준이 되어 전체 상태를 알리고, 상대가 보낸 수는 모두가 같은 규칙으로 확인합니다. 새로 들어온 방문객에게도 진행 중인 대국이 바로 보입니다.
- 호스트가 기원을 떠나면 그 대국은 정리됩니다. 자유 채팅은 없고 정해진 인사 · 한마디 · 한 판 청하기만 있습니다.

## 무량사와 연결하기
`src/main.js` 맨 위의 `MURYANGSA_URL`에 무량사 주소를 넣으면 상단 메뉴와 설정에 「무량사 ↗」 링크가 나타납니다.
```js
const MURYANGSA_URL = "https://계정.github.io/muryangsa/";
```
무량사 쪽에서도 메뉴에 무량기원 주소를 걸어 두면 두 공간이 하나의 세계관으로 이어집니다.

## 로컬 실행 · 공개
`index.html`을 더블클릭(file://)하면 ES 모듈과 작업자가 막힙니다. 반드시 서버로 여세요(인터넷 연결 필요: Three.js · Trystero · 글꼴 CDN).
```bash
python -m http.server 8000   # http://localhost:8000
```
GitHub Pages 공개 방법은 무량사와 같습니다(새 저장소에 이 폴더 내용을 올리고 Settings → Pages → main / root). HTTPS여야 방문객 연결이 동작합니다.

## 알아 두기
- 인공지능은 브라우저 안에서 계산합니다. 19줄 고급은 한 수에 3~4초 정도 생각합니다. 프로 수준은 아니며, 입문~초급자가 즐겁게 둘 수 있는 정도를 목표로 했습니다.
- 자동 계가는 추정이라 세키 · 복잡한 사활에서는 실제와 다를 수 있습니다. 끝내기를 충분히 두고 패스하면 정확해집니다.
- 영문 표기는 무량사(MURYANGSA)에 맞춰 **MURYANG BADUK INSTITUTE**로 했습니다.
- 무량기원은 실제 바둑 단체와 무관한 독립적인 가상 문화 프로젝트입니다.

## v2에서 달라진 것
- **아바타**: 기본 복장이 정장(재킷·셔츠·넥타이)으로, 기본 머리가 짧은 머리로 바뀌었습니다. 옷 꾸미기는 현대 복장으로 교체 — 옷(정장·셔츠·니트·후드티·코트) · 상의/하의/넥타이 색 · 머리 모양 8종 · 머리 색 · 소품(안경·선글라스·야구모자·비니·헤드폰·에어팟·회원증 목걸이).
- **안내 데스크 NPC (안내원 한결)**: 가까이 가서 E. 회원 등록(닉네임·기력·주로 두는 판 → 회원증 발급), 회원증 보기, 닉네임 변경, 시설 안내(원하는 곳으로 바로 이동), 빈 대국석 안내, 대국 중계, 내 기보, 이용 안내.
- **회원 · 닉네임**: 닉네임은 회원 등록 후 정할 수 있고, 바꾼 뒤에는 **밤 12시(기기 시간)가 지나야** 다시 바꿀 수 있습니다. 회원은 **머리 위에 닉네임**이 표시됩니다(다른 방문객에게도). 비회원은 무작위 이름만 쓸 수 있습니다.
- **엘리베이터 · 2층**: 로비 입구 왼편 엘리베이터(E)로 2층에 오릅니다. 2층에는 **대국실 4칸**(전통 바둑판·방석)과 **대회실**(무대 위 대회 대국석 2곳, 관객석, 대형 전광판 2개)이 있습니다.
- **대국 중계**: 대회실 대국은 대회실 전광판과 1층 대국장 전광판·로비 화면에 실시간 중계되고, 형세(흑·백 승률 막대)도 함께 보여 줍니다. **J(대국 중계)** 목록에서 기원 어디서든 원하는 대국을 골라 관전할 수 있습니다.
- **기보**: 대국이 끝나면(계가·기권) 기보가 자동 저장됩니다. **I(내 기보)** 또는 연구·분석실 컴퓨터 앞 의자에 앉으면 「내 기보 · 무량기원 대국 · 명국 기보」를 봅니다. 처음/이전/다음/끝, 자동 재생, **다음 수 맞히기**, SGF 내려받기. 기원 대국 기보는 함께 접속한 방문객끼리 나누어 보관합니다.
- **명국 기보 50판**(실제 기보, 출처: 공개 데이터셋 yenw/computer-go-dataset — 모든 수를 규칙 엔진으로 끝까지 검증): 1989 응씨배 결승 1~5국, 조훈현–이창호 7판, 이창호–이세돌 7판, 이세돌–구리 10번기 1~8국, 커제–이세돌·박정환, 이세돌–이야마 유타, 이창호–마샤오춘, 조치훈–고바야시 고이치, 알파고–이세돌 1~5국, 알파고–커제 1~3국, 알파고 마스터 온라인 대국 6판. 분류(한국 바둑의 명승부 · 세계 대회 · 인공지능 · 일본 바둑)와 이름·연도 검색.
- **기보 서가**: 연구·분석실 오른쪽 서가에서 Q → 기보를 골라 「들고 가기」 → 손에 책을 든 채 빈 바둑판에 앉으면 그 기보를 판에 한 수씩 놓아 볼 수 있습니다(다른 방문객에게도 보임).
- **교육원 바둑 강좌**: 정 사범(NPC) 또는 L. 10강(바둑판과 돌 · 활로 · 따내기 · 단수 · 자충수 · 패 · 집 · 두 눈 · 축 · 첫 대국), 직접 두어 보는 문제와 힌트, 진도 저장. 마지막엔 9줄 입문 AI와 첫 대국. 강의판은 교육원 벽 자석판에도 나타납니다.
- **소파 · 벤치**: 로비 소파, 관전석, 광장 벤치, 2층 관객석에 E로 앉습니다.
- **다과 코너**(대국장 앞 오른쪽): 정수기(U) · 믹스커피(Q). 컵을 들고 가끔 한 모금 마십니다.
- 로비 입구의 안내판은 없앴습니다(안내원이 대신 안내). 중앙 대국장 입구는 로고 벽 양옆 두 개의 출입구(문틀 · 열린 유리문 · 현판)로 정리했고, 안내 데스크는 낮추고 안내원은 데스크 뒤 컴퓨터 옆에 섭니다. 2층 대회 대국석은 가로(관객석에서 두 대국자가 옆모습으로 보이게)로 놓았습니다. 바둑판 창 · 기보 창 · 강좌 창은 화면 가운데에 뜹니다.

## v2.3에서 달라진 것
- **로딩 화면**: 9줄 바둑판에 돌이 한 수씩 놓이고, 위기십결(圍棋十訣)이 번갈아 나옵니다.
- **실내에서 시작**: 첫 화면과 시작 위치가 1층 로비 안입니다.
- **대국 시간**: 무제한 · 10분 · 20분 · 30분 + 초읽기 30초 3회. 다 쓰면 시간패.
- **급수 조정**: 회원끼리 둔 대국만 반영. 이기면 +1, 지면 −1, +3이면 한 급 승급, −3이면 강급. 머리 위 닉네임 옆에 급수 표시.
- **인공지능 대국은 2층 연습실에서만**: 의자 하나짜리 연습석 8개(「무량 AI」 모니터). 다른 대국석은 방문객끼리만 둡니다.
- **주간 명예의 전당**: 매주 월요일 0시에 새로 시작. 회원 대국의 승 − 패 순위 10위까지, 1·2·3위 금·은·동 강조. 로비 오른쪽 벽 게시판, 「🏆 명예의 전당 (O)」, 안내 데스크에서 볼 수 있고 지난주 기록도 남습니다.
  - 서버 없이 방문객끼리 기록을 주고받는 방식이라, 같은 시간에 접속한 적이 있는 사람들의 기록이 모입니다.
- **천장 높이**: 1층 천장을 높여 카메라가 걸리지 않게 했습니다.
- **바깥 풍경**: 겹겹의 산 능선, 아파트 단지, 유리 고층 빌딩, 횡단보도 · 신호등, 「무량기원 앞」 버스 정류장, 오가는 차와 버스.
